# DA-2-23

## Описание проекта
Создание агрегированных признаков для набора данных Iris
Этот проект решает задачу генерации новых признаков путем агрегации числовых данных по категориальным группам в известном наборе данных Ирисов (Iris Dataset).

## Решаемая задача
Основная задача — создать дополнительные признаки для исходного набора данных, вычисляя статистические показатели (среднее значение, стандартное отклонение и количество наблюдений) для числовых характеристик внутри каждой категориальной группы.

Конкретные шаги, выполняемые в проекте:

- Загрузка данных: Автоматическая загрузка и подготовка набора данных Iris из библиотеки scikit-learn.

- Создание категориального признака: Преобразование целевой переменной (вид ириса) в категориальный признак для группировки.

- Расчет статистики по группам: Вычисление статистических показателей (mean, std, count) для числовых столбцов внутри каждой категории.

- Объединение данных: Слияние рассчитанной статистики с исходным DataFrame для создания обогащенного набора данных.

- Визуализация и сохранение: Отображение результата и опциональное сохранение в CSV-файл.

## Как использовать реализованные функции
Код проекта модульный и содержит три основные функции, которые можно легко переиспользовать в других проектах для аналогичных задач.

1. Функция ```calculate_numeric_column_statistics```

    Эта функция вычисляет статистические показатели для указанного числового столбца, сгруппированные по категориальному признаку.

    **Аргументы:**

    ```df (pd.DataFrame)```: Исходный DataFrame с данными для анализа.

    ```column_name (str)```: Название числового столбца, для которого рассчитывается статистика.

    ```categoric_col_name (str)```: Название категориального столбца, по которому производится группировка.

    ```statistics_names (list[str])```: Список статистик, которые будут вычислены. Подается в функцию ```groupby.agg```

    **Возвращаемое значение:**

    ```pd.DataFrame | None```: DataFrame с рассчитанной статистикой или None в случае ошибки.

    **Пример использования:**

    ```python
    from DA_1_21 import calculate_numeric_column_statistics

    ## Расчет статистики для столбца 'sepal length (cm)' по категориям 'species'
    statistics = calculate_numeric_column_statistics(
            df=df,
            column_name="sepal length (cm)",
            categoric_col_name="species",
            statistics_names=["mean", "std", "count"],
        )

    if statistics is not None:
        print(statistics.head())
    ```

2. Функция ```merge_data_and_stats```

    Эта функция объединяет исходный DataFrame с рассчитанной статистикой по общему столбцу.

    **Аргументы:**

    ```df (pd.DataFrame)```: Исходный DataFrame с данными.

    ```stats (pd.DataFrame)```: DataFrame со статистикой, полученный из функции calculate_numeric_column_statistics.

    ```column_name (str)```: Название общего столбца для объединения (категориальный признак).

    **Возвращаемое значение:**

    ```pd.DataFrame | None```: Объединенный DataFrame или None в случае ошибки.

    **Пример использования:**

    ```python
    from DA_1_21 import merge_data_and_stats

    # Объединение исходных данных с рассчитанной статистикой
    enriched_data = merge_data_and_stats(df, statistics, "species")

    if enriched_data is not None:
        print(enriched_data.head())
    ```

3. Функция save_and_visualize

    Эта функция отображает DataFrame в консоли и при необходимости сохраняет его в CSV-файл.

    **Аргументы:**

    ```df (pd.DataFrame)```: DataFrame для отображения и сохранения.

    ```save_name (str | None)```: Имя файла для сохранения (например, "results/enriched_data.csv"). Если None или пустая строка, сохранение не производится.

    **Пример использования:**

    ```python
    from DA_1_21 import save_and_visualize

    # Визуализация и сохранение результата
    save_and_visualize(enriched_data, save_name="results/enriched_iris.csv")

    # Только визуализация без сохранения
    save_and_visualize(enriched_data)
    ```

## Запуск проекта
Убедитесь, что установлены необходимые библиотеки:

```bash
pip install -r requirements.txt
```
Запустите скрипт из командной строки:

```bash
python3 task.py
```
Это выполнит полный pipeline:

- Загрузит данные Iris

- Создаст категориальный признак

- Рассчитает статистику для длины чашелистика по видам ирисов

- Объединит статистику с исходными данными

- Отобразит результат и сохранит его в файл iris_with_statistics.csv
