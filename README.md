# DA-3-44

## Описание проекта
Создание дашборда для визуализации временных рядов

Этот проект решает задачу комплексной визуализации временного ряда, включая анализ исходных данных, скользящего среднего, декомпозиции на компоненты и распределения остатков.

## Решаемая задача
Основная задача — создать информативный дашборд для анализа временного ряда, который включает в себя:

- Исходный временной ряд

- Сглаженный ряд с помощью скользящего среднего

- Декомпозицию на тренд и сезонную составляющую

- Анализ распределения остатков

Конкретные шаги, выполняемые в проекте:

1) Генерация временного ряда: Используется функция generate_time_series из DA-2-45 для создания синтетического временного ряда с заданной сезонностью.

2) Расчет скользящего среднего: Применяется функция moving_average из DA-2-41 для сглаживания временного ряда.

3) Декомпозиция временного ряда: Используется метод сезонной декомпозиции из библиотеки statsmodels для разложения ряда на тренд, сезонную составляющую и остатки.

4) Визуализация: Построение сетки графиков 2x2 для отображения всех компонентов анализа.

5) Сохранение результатов: Сохранение полученного дашборда в файл PNG.

## Как использовать реализованные функции

Код проекта модульный и содержит несколько функций, которые можно переиспользовать в других проектах для аналогичных задач.

- Функция ```get_dataframe```

    Эта функция генерирует временной ряд в виде DataFrame с помощью функции generate_time_series из DA-2-45, переименовывает столбец и добавляет постоянный сдвиг.

    **Аргументы:**

    ```start_date (str)```: Дата начала временного ряда в формате, который может быть распознан pandas (например, "2024-01-01").

    ```num_periods (int)```: Количество периодов (точек данных) во временном ряде.

    ```seasonality_period (int)```: Период сезонности для генерации временного ряда.

    ```value_name (str)```: Название столбца со значениями временного ряда.

    ```shift (float)```: Постоянный сдвиг, добавляемый ко всем значениям временного ряда.

    **Возвращаемое значение:**

    ```pd.DataFrame | None```: DataFrame с временным рядом или None в случае ошибки.

    **Пример использования:**

    ```python
    from DA_3_44 import get_dataframe

    df = get_dataframe(
        start_date="2024-01-01",
        num_periods=100,
        seasonality_period=33,
        value_name="Rubles",
        shift=10
    )

    if df is not None:
        print(df.head())
    ```

- Функция ```decompose```

    Эта функция выполняет декомпозицию временного ряда на тренд, сезонную составляющую и остатки с использованием модели additive. Написана на основе функции ```decompose_and_plot``` из DA_2_45

    **Аргументы:**

    ```df (pd.DataFrame)```: DataFrame, содержащий временной ряд.

    ```seasonality_period (int)```: Период сезонности, используемый для декомпозиции.

    ```value_name (str)```: Название столбца со значениями временного ряда.

    **Возвращаемое значение:**

    ```dict | None```: Словарь с компонентами декомпозиции (observed, trend, seasonal, resid) или None в случае ошибки.

    **Пример использования:**

    ```python
    from DA_3_44 import decompose

    decomposition = decompose(df, seasonality_period=33, value_name="Rubles")

    if decomposition is not None:
        print(decomposition["trend"].head())
    ```

- Функция ```plot_from_dict```

    Эта функция визуализирует дашборд из словаря с массивами данных и может сохранить график в файл.

    **Аргументы:**

    ```arrays (dict)```: Словарь, содержащий следующие ключи:
    - "original": исходный временной ряд (pd.DataFrame)
    - "ma": скользящее среднее (pd.DataFrame)
    - "decomposed": кортеж (trend, seasonal) из декомпозиции
    - "resids": остатки от декомпозиции (pd.Series)

    ```value_name (str)```: Название величины, используемое для подписей осей.

    ```save_name (str | None)```: Имя файла для сохранения графика (например, "cost_dashboard.png"). Если None или пустая строка, сохранение не производится.

    **Пример использования:**

    ```python
    from DA_3_44 import plot_from_dict

    plot_dict = {
        "original": df,
        "ma": ma_df,
        "decomposed": (decomposition["trend"], decomposition["seasonal"]),
        "resids": decomposition["resid"],
    }

    plot_from_dict(plot_dict, value_name="Rubles", save_name="my_dashboard.png")
    ```

## Запуск проекта
Убедитесь, что установлены необходимые библиотеки:

```bash
pip install -r requirements.txt
```
Запустите скрипт из командной строки:

```bash
python3 task.py
```

Это выполнит полный pipeline:

- Сгенерирует временной ряд начиная с 2024-01-01, с 99 периодами, сезонностью 33, сдвигом 10 и названием столбца "Rubles".

- Выполнит декомпозицию временного ряда.

- Рассчитает скользящее среднее с окном 5.

- Построит дашборд и сохранит его в файл "cost_dashboard.png".

## Особенности реализации
Проект использует функции из модуля DA_2_41 для расчета скользящего среднего и модуля DA_2_45 для генерации временного ряда. Также на основе функции из DA_2_45 написана функция decompose.
