# DA-1-21

## Описание проекта
Анализ корреляции для набора данных Boston Housing
Этот проект решает задачу анализа корреляции между числовыми признаками в известном наборе данных о ценах на жилье в Бостоне (Boston Housing Dataset).

## Решаемая задача
Основная задача — исследовать взаимосвязи между различными характеристиками недвижимости (такими как уровень преступности, количество комнат, налог на имущество и т.д.) и их влияние на целевую переменную — стоимость домов (MEDV).

Конкретные шаги, выполняемые в проекте:

- Загрузка данных: Автоматическое скачивание и подготовка набора данных из исходного репозитория.

- Расчет корреляции: Вычисление матрицы корреляции Пирсона для всех числовых столбцов в данных. Коэффициент корреляции показывает силу и направление линейной связи между признаками (от -1 до +1).

- Визуализация: Построение тепловой карты (heatmap) для наглядного представления матрицы корреляции. Это позволяет быстро определить наиболее сильные положительные и отрицательные связи.

## Как использовать реализованные функции
Код проекта модульный и содержит три основные функции, которые можно легко переиспользовать в других проектах для аналогичных задач.

1. Функция ```get_dataset```

    Эта функция загружает и подготавливает набор данных из указанного URL-адреса.

    **Аргументы:**

    ```data_url (str)```: Прямая ссылка для скачивания файла данных.

    ```columns (list | None)```: Список с названиями столбцов. Если None, будут использованы исходные названия из файла.

    **Возвращаемое значение:**

    ```pd.DataFrame | None```: DataFrame с загруженными данными в случае успеха, или None, если в процессе загрузки произошла ошибка.

    **Пример использования:**

    ```python
    # Загрузка стандартного Boston dataset
    from my_analysis_module import get_dataset

    URL = "https://lib.stat.cmu.edu/datasets/boston"
    COLUMNS = ["CRIM", "ZN", "INDUS", "CHAS", "NOX", "RM", "AGE", "DIS", "RAD", "TAX", "PTRATIO", "B", "LSTAT", "MEDV"]

    df = get_dataset(URL, COLUMNS)
    if df is not None:
        print(df.head())
    ```

2. Функция ```calculate_correlation```

    Эта функция вычисляет матрицу корреляции для числовых столбцов переданного DataFrame.

    **Аргументы:**

    ```dataset (pd.DataFrame)```: Исходный DataFrame с данными для анализа.

    **Возвращаемое значение:**

    ```pd.DataFrame | None```: Матрица корреляции в виде DataFrame, где индексы и столбцы — это названия признаков. Возвращает None в случае ошибки.

    **Пример использования:**

    ```python
    from my_analysis_module import calculate_correlation

    # Предположим, что `my_dataframe` - это любой DataFrame с числовыми данными
    correlation_matrix = calculate_correlation(my_dataframe)

    if correlation_matrix is not None:
        # Посмотреть корреляцию целевой переменной 'MEDV' с другими признаками
        print(correlation_matrix['MEDV'].sort_values(ascending=False))
    ```

3. Функция ```draw_heatmap```

    Эта функция визуализирует матрицу корреляции (или любой другой DataFrame) в виде тепловой карты с помощью библиотеки seaborn.

    **Аргументы:**

    ```data (pd.DataFrame)```: DataFrame с данными для визуализации (например, матрица корреляции).

    ```save_name (str | None)```: Имя файла для сохранения графика (например, "my_heatmap.png"). Если аргумент не указан или равен None/пустой строке, график не сохраняется.

    **Пример использования:**

    ```python
    from my_analysis_module import draw_heatmap

    # Визуализация матрицы корреляции
    draw_heatmap(correlation_matrix, save_name="analysis/correlation_heatmap.png")

    # Визуализация без сохранения
    draw_heatmap(correlation_matrix)
    ```

## Запуск проекта
Убедитесь, что установлены необходимые библиотеки:

``` bash
pip install -r requirements.txt
```

Запустите скрипт из командной строки:

``` bash
python3 task.py
```
Это загрузит данные, рассчитает корреляции, отобразит тепловую карту и сохранит её в файл corr_mat.png.
